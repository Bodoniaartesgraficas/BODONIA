# Proyecto — base de trabajo

Este repositorio reúne el contexto, las decisiones y los materiales del proyecto. La fuente de verdad inicial es el brief en `01_brief/brief.md`.

## Estructura

- `00_admin/` — alcance, presupuesto, calendario y accesos (evita guardar secretos).
- `01_brief/` — objetivos, público, mensaje, restricciones y criterios de éxito.
- `02_investigacion/` — investigación, competencia y referencias; guarda enlaces en `referencias.md` y archivos en `referencias/`.
- `03_estrategia/` — enfoque, prioridades y decisiones aprobadas.
- `04_contenido/` — textos, guiones, datos y materiales editoriales.
- `05_diseno/` — wireframes, diseño y recursos visuales.
- `06_produccion/` — implementación, especificaciones técnicas y control de calidad.
- `07_entregables/` — versiones listas para compartir o entregar.
- `08_reuniones/` — agendas, notas y próximos pasos.
- `99_archivo/` — material obsoleto que conviene conservar.

## Convenciones

- Nombra los archivos con `AAAA-MM-DD-tema-v01.ext` cuando tengan versiones.
- Registra decisiones relevantes en `03_estrategia/decisiones.md`.
- No incluyas contraseñas, claves API ni datos personales sensibles.
