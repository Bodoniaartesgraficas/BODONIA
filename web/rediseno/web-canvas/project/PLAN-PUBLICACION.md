# Bodonia Artes Gráficas — plan para publicar la web

Cuando el cliente diga que tiene la web definitiva, darle TODOS estos pasos, uno a uno.

## Fase 1. Cerrar el diseño (cliente + Claude)
1. Elegir versión definitiva: Inicio (Main), Variante loca (Loca) o Copia.
2. Confirmar datos: tel. 648 82 32 50, info@bodonia.es, C/ Gredos nº 27, 18140 La Zubia (Granada), horario L-V 9:00–20:00.
3. Claude actualiza textos legales: quitar bodoniaartesgraficas.wordpress.com, poner bodonia.es, cookies: la web no usa cookies.

## Fase 2. Preparar archivos (Claude)
4. Exportar a HTML normal con fotos, vídeos, logo y fuente Bodoni Moda alojada en la propia web (no Google Fonts).
5. Formulario "Pide información" con Netlify Forms (adjuntos, aviso a info@bodonia.es).
6. Título/descripción para Google, favicon, imagen para compartir (Open Graph).
7. Entregar .zip.

## Fase 3. Netlify (cliente, guiado)
8. Cuenta gratis en Netlify con info@bodonia.es.
9. Arrastrar la carpeta → dirección provisional *.netlify.app.
10. Revisar en ordenador y móvil; probar formulario.
11. Netlify → añadir dominio bodonia.es → anotar los registros DNS que indica.

## Fase 4. Dominio (informático, OVH)
12. Claude redacta nota para el informático: añadir registros de Netlify en OVH SIN tocar los MX del correo.
13. Esperar propagación (minutos a 24 h); comprobar candado https.
14. Comprobar que el correo info@bodonia.es sigue llegando.

## Fase 5. Enlazar en todas partes (cliente)
15. Perfil de Empresa de Google: Editar perfil → Contacto → sitio web https://bodonia.es (revisar tel., horario, dirección).
16. Instagram: Editar perfil → Enlaces → https://bodonia.es.
17. Facebook: sitio web + portada nueva.
18. WhatsApp Business: sitio web.
19. Firma de correo.
20. Material impreso futuro: bodonia.es.

## Fase 6. Despedir WordPress
21. Entrada única "Nos hemos mudado a bodonia.es" unas semanas.
22. Borrar WordPress.

Opcional: Google Search Console.
