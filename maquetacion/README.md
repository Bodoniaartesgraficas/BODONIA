# Maquetación

## Objetivo

Aligerar el trabajo de maquetación del día a día. Aquí se suben los archivos de origen (textos, imágenes, pruebas, indicaciones) de los trabajos que hay que maquetar, y aquí se dejan las versiones maquetadas.

## Cómo usarlo

1. Crea una subcarpeta por trabajo (por ejemplo `2026-10-cartel-fiestas/`).
2. Sube dentro los archivos de origen y una nota con lo que necesitas: formato, medidas, sangrado, número de páginas y fecha de entrega.
3. Apunta el trabajo en la tabla de abajo.
