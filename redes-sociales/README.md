# Redes sociales

## Objetivo

Mejorar las redes sociales de Bodonia con una imagen coherente: patrones y plantillas de publicación, calendario de contenidos y piezas listas para publicar.

Contexto completo (marca, preferencias, calendario de publicación y pendientes): [`docs/resumenes/2026-10-redes-sociales.md`](../docs/resumenes/2026-10-redes-sociales.md). Reel de En Noir: [`docs/resumenes/2026-10-reel-en-noir.md`](../docs/resumenes/2026-10-reel-en-noir.md).

## Contenido de `instagram/` (de `z INSTAGRAM.zip`)
